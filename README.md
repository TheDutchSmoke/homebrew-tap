# TheDutchSmoke/homebrew-tap

Homebrew-formules van TheDutchSmoke.

```sh
brew install thedutchsmoke/tap/<formule>
```

| Formule | Wat |
| --- | --- |
| `twitch-iina` | Twitch in IINA via Streamlink Twitch GUI, met 2K (H.265) en automatisch terug naar live. [Repo](https://github.com/TheDutchSmoke/twitch-iina) |

SofaStream heeft een eigen tap: `thedutchsmoke/sofastream`.
